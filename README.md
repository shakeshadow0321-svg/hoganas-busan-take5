# Hoganas Busan Take 5 demo

## GitHub upload
Upload all files and the `src` folder to the repository root.

## Vercel
1. Import the GitHub repository in Vercel.
2. Framework preset: Vite.
3. Build command: `npm run build`.
4. Output directory: `dist`.
5. Click Deploy.

## Important
This demo stores records only in the browser's localStorage. It is not a shared production database.
